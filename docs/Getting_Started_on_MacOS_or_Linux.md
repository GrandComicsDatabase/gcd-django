# Getting Started on macOS or Linux

This setup guide is retired. Use the current
[development environment chooser](development/CORE_SETUP.md).

- For Docker-free development, start with [native macOS](development/NATIVE_MACOS.md)
  or [native Ubuntu 24.04](development/NATIVE_UBUNTU.md), then
  [shared native setup](development/NATIVE_COMMON.md).
- For container-based development, use the chooser's Docker quick start or
  [VS Code Dev Container](development/DEV_CONTAINER.md).

Preserve existing databases and local settings; do not mix historical package
or configuration instructions with the new guides. See
[supported versions](development/SUPPORTED_VERSIONS.md) and
[troubleshooting](development/TROUBLESHOOTING.md).

This filename remains for existing links. Earlier instructions remain in Git
history, not as a supported setup option.
