# Getting Started on Windows

This direct native Windows setup guide is retired. Use
[Ubuntu 24.04 under WSL2](development/WSL2.md), with either native Linux tools
or Docker Desktop integration, instead of installing Python and MySQL directly
into Windows for GCD.

The [development environment chooser](development/CORE_SETUP.md) describes the
available paths and their validation limits. Preserve existing distributions,
databases and local changes before moving an older installation. Do not mix
old Windows package instructions with the current guides.

See [supported versions](development/SUPPORTED_VERSIONS.md) and
[troubleshooting](development/TROUBLESHOOTING.md). This filename remains for
existing links; earlier instructions remain in Git history.
