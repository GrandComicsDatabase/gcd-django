# Getting Started

This setup guide is retired. Start with the current
[development environment chooser](development/CORE_SETUP.md).

It covers Docker Compose with sample data or a catalog dump, Docker-free
[macOS](development/NATIVE_MACOS.md) and [Ubuntu](development/NATIVE_UBUNTU.md),
[Windows with WSL2](development/WSL2.md), and the
[VS Code Dev Container](development/DEV_CONTAINER.md).

Do not combine old manual configuration or fixture-loading instructions with
the current setup. For existing installations, preserve data and local changes
before choosing a migration path. See [troubleshooting](development/TROUBLESHOOTING.md)
and the root [README](../README.md#workflow) for the contribution workflow.

This filename remains so old links continue to work. Earlier instructions are
available in Git history, not as an alternative installation recipe.
